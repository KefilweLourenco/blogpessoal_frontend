# Implementação 05 a 08

## Contexto

Neste trecho do Cookbook, a base visual inicial do projeto front-end foi estruturada.

## O que foi implementado

- instalação e configuração do Tailwind CSS no projeto Vite
- importação global do Tailwind em `src/index.css`
- criação da `Navbar`
- criação do `Footer`
- estilização da `Home` com Tailwind
- organização inicial do layout com `Navbar`, `Home` e `Footer`
- instalação da biblioteca `@phosphor-icons/react`

## Resultado no projeto

- layout principal do Blog Pessoal passou a existir visualmente
- o projeto ganhou identidade visual inicial
- a Home deixou de usar estilos inline e passou a usar classes utilitárias

## Arquivos principais envolvidos

- `src/App.tsx`
- `src/index.css`
- `src/pages/home/Home.tsx`
- `src/components/navbar/Navbar.tsx`
- `src/components/footer/Footer.tsx`
- `vite.config.ts`
