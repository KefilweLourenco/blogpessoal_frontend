# Implementação 09 a 12

## Contexto

Neste bloco, o projeto deixou de ser uma página estática e passou a usar rotas com React Router.

## O que foi implementado

- instalação do `react-router-dom`
- configuração das rotas no projeto
- adaptação da `Navbar` para navegação com `Link`
- criação da página de cadastro
- criação da página de login
- estilização inicial das páginas de cadastro e login com Tailwind

## Rotas criadas

- `/`
- `/home`
- `/cadastro`
- `/login`

## Resultado no projeto

- o front-end passou a navegar entre telas sem recarregar a página
- o projeto ganhou estrutura de autenticação visual
- a base para integração com backend ficou pronta

## Arquivos principais envolvidos

- `src/App.tsx`
- `src/components/navbar/Navbar.tsx`
- `src/pages/cadastro/Cadastro.tsx`
- `src/pages/login/Login.tsx`
